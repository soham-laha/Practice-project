## Reproducibility and limits

- Local Node **22.22.3** / npm 10.9.8 / Python **3.11.2**; verified remote Node **22 and 26** / Python **3.12**. CI dependencies are pinned by lockfiles; actions by immutable SHA.
- Local static/build → pytest → Vitest → design/dependency checks → fresh production services → browser/HTTP checks were run in that order after application corrections. Later repository-only changes are separately tested rather than passed off as a new app build.
- Standalone local Python 3.12 downloads failed with TLS/EOF. That local limitation no longer means Python 3.12 is entirely untested: real GitHub runs passed.
- Linux Chromium and its libraries are installed from npm; browser web security is not disabled to force success. No login or centralized learner database is required.
- Corrections include safe KaTeX rendering/canonical options, strict provider roots/IDs/exam, bounded SymPy subprocesses with minimal environments, IndexedDB fallback migration, validated backups and grace totals, timer/submission race fixes, correct recovery evidence and fixed-origin upload discovery. Tests cover those regressions.
- All six source PDF pages are mapped in `SYSTEM_ARCHITECTURE.md`. Four literal custom-design fields were unspecified; research-backed defaults are documented, not misrepresented as exact supplied artwork.
- SymPy verifies bounded expression/certificate/domain/unit consistency, **not** arbitrary OCR, diagram/natural-language interpretation or physics correctness. Item parameters and SATO/tier thresholds are illustrative heuristics, not population calibration, causal score gain, a rank predictor or a mastery certificate.
- Advanced reference items use single-correct +4/−2, generated items may use +4/−1 or +4/−2. Every variable multi-correct/partial-credit Advanced section is not implemented.
- localStorage keys are not encrypted. Application log avoidance does not control a hosting operator's APM/proxy capture. Trusted TLS termination, edge quotas and host limits remain operator responsibilities.
- Root MIT remains unchanged. `THIRD_PARTY_NOTICES.md` and preserved upstream OFL/native notices are a technical inventory, **not** legal clearance or an assertion that all dependencies are MIT. Attribution is not ownership or repository access.
