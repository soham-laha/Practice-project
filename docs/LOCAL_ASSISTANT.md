# Optional on-device text assistant

## Scope and use

Open **Build a drill → On-device text assistant** and read the download notice. **Load local assistant** is the explicit opt-in. Opening the page or disclosure does not create a worker, download the runtime/model, read the Gemini key, or send a prompt.

This is an experimental short-text helper, not a substitute for the forge. It cannot read an image/PDF, produce a checked `targetjee.item.v2` drill, verify mathematics, estimate a rank, or use the learner's saved drill history. Its suggestions can be wrong. The existing checked reference questions remain usable without it or Gemini.

| Setting           | Implementation                                                                                                                                                                                                                                                 |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Model             | `SmolLM2-360M-Instruct-q4f32_1-MLC`                                                                                                                                                                                                                            |
| Runtime           | Exactly `@mlc-ai/web-llm@0.2.88`, bundled locally and imported lazily in a dedicated worker                                                                                                                                                                    |
| Requirements      | A secure context, WebGPU-capable browser/device and enough memory/storage; an exposed WebGPU interface does not guarantee a compatible adapter                                                                                                                 |
| Resource guidance | Several hundred MB of model downloads. The runtime catalog estimates **579.61 MB VRAM** at its default settings; this is not a measured download size or memory guarantee. Allow browser/runtime overhead. Actual needs, performance and browser support vary. |
| Bounds            | One turn, 800 input characters, 2048-token context, at most 180 generated tokens and 3000 displayed characters                                                                                                                                                 |
| Deadlines         | Load 10 minutes; suggestion 60 seconds; removal 30 seconds                                                                                                                                                                                                     |
| Transcript        | In component/worker memory only; chat reset after each answer, worker terminated on unmount; not saved/exported with learner data                                                                                                                              |
| Provider fallback | None. Local failure never switches to Gemini, another model, a paid provider or an invented drill.                                                                                                                                                             |

**Stop** terminates the worker during load/inference. **Unload from memory** does the same after loading. GPU/worker memory is released by the browser; completed/partial cached files can remain. **Remove downloaded model** deletes this model's matching entries from the three pinned runtime CacheStorage scopes (`webllm/model`, `webllm/config`, `webllm/wasm`). It does not fetch a manifest or delete unrelated models/caches. A full confirmed local-data reset also removes this cache. If storage deletion fails, the UI does not claim success; site-data controls in the browser remain the fallback.

## Network, privacy and CSP

After consent the runtime downloads the model's config/tokenizer/weight files from Hugging Face and compiled model WASM from GitHub. Those hosts/CDNs see normal download metadata such as the requesting IP; this is not an anonymous download. The application's inference path contains no prompt upload or key/history lookup. This is locality, not encrypted storage or a promise against a compromised browser, package or device.

The fixed catalog record comes from the pinned WebLLM package. Its compiled-model URL uses `web-llm-models/v0_2_87/base/SmolLM2-360M-Instruct-q4f32_1_cs1k-webgpu.wasm` despite the npm version being 0.2.88. Upstream artifact URLs use mutable `main` revisions; npm pinning is **not** artifact integrity pinning.

Production allows same-origin workers and WASM compilation, not general JavaScript `unsafe-eval`, `blob:` workers, arbitrary remote scripts, or wildcard download hosts. Connection exceptions are explicit Hugging Face file/CDN hosts and `raw.githubusercontent.com`, plus the configured HTTPS upload API. The [official Hub download/firewall guide](https://github.com/huggingface/hub-docs/blob/819a5a8338b06d03e503413173c7594d1ba0ff64/docs/hub/models-downloading.md) informed the named CDN entries. The selected artifact's actual redirect chain was **not** downloaded/verified here. A later upstream host change can cause a visible local-load error and should be reviewed, not fixed by blindly allowing all HTTPS origins. Next development alone permits the evaluation its development runtime needs.

## Licenses and verification boundary

The [official SmolLM source repository](https://github.com/huggingface/smollm/tree/438be18dae658a638f3a6976fdf5190bb6d68619) declares Apache-2.0. Its original license is preserved at `public/notices/SmolLM-upstream-LICENSE.txt` (Git blob `261eeb9e9f8b2b4b0d119366dda99c6fd7d35c64`, also present at the older [SmolLM2-specific revision](https://github.com/huggingface/smollm/tree/997ca0765a2a7bfc87b1335c67c9ef1ae3534e8a)). The original WebLLM npm Apache license is also copied unchanged. See [third-party notices](../THIRD_PARTY_NOTICES.md) for the runtime dependency inventory.

No weights or downloaded compiled model library are redistributed in this repository. The Hugging Face conversion's own license files and the selected compiled binary's license/integrity were **not independently retrieved**; the binary-library repository does not expose a repository-level license in the queried GitHub metadata. The upstream source license/inventory is not full clearance of every remote/bundled artifact. Review those artifacts before mirroring or distributing them yourself.

Tests cover explicit consent, no unsolicited requests, unsupported WebGPU, bounded input/output, single-turn reset, deadlines, Stop/Unload, worker termination, safe errors, no cloud fallback, and removal of complete/partial **synthetic** cache entries without a network request. The real bundled worker/runtime also reaches its config-fetch boundary under production CSP with that request intercepted before network access. This verifies bundling/import and the blocked-download error path, **not** model loading, GPU inference, numerical quality, download size, performance or offline-after-download behavior. Those remain device acceptance gates; no model weights or paid Gemini calls were used in this task.
